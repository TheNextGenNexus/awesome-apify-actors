## Why this list exists

After publishing nearly 500 actors on Apify, we noticed something: there is no single, honest place to find the *best* actors for a given job. The Apify Store has 20,000+ actors and ranks mostly by raw popularity — which favors a handful of household-name scrapers and buries excellent niche tools.

This list is curated by an actual operator. We pick actors based on:

1. **Maintenance** — is it still being updated?
2. **Reliability** — does it actually finish runs without failing?
3. **Output quality** — does the data come back clean and usable?
4. **Pricing fairness** — is it priced like a tool or like a tollbooth?
5. **Coverage** — does it fill a real gap on the platform?

We include our own actors when they qualify on the same criteria. We don't include them when they don't.

## Contributing

Contributions welcome. To add an actor:

1. Open a PR adding one bullet to the appropriate category.
2. Format: `- [Title](https://apify.com/USER/NAME?fpr=2ayu9b) — 8-12 word description. *Pricing tag* \`@USER\``
3. The actor must be **public**, **maintained** (modified in the last 12 months), and **not broken** on the latest run.
4. Keep descriptions honest. No marketing copy. State what it scrapes and any meaningful limitations.
5. One actor per PR for new categories; bundle multiple actors per PR within an existing category.

Affiliate code `?fpr=2ayu9b` is appended to every Apify link. This funds list maintenance. If you'd prefer your entry use a different code (or no code), say so in the PR — we'll honor it.

To **remove** a broken actor, open a PR or an issue with a link to a recent failed run.
